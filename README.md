# Ernesto Cruz

I write UEFI firmware with EDK II and Linux systems code in C.

[portfolio.faky.dev](https://portfolio.faky.dev) · [ernestobritocruz05@gmail.com](mailto:ernestobritocruz05@gmail.com)

## Stuff I do

- Firmware and UEFI: C, EDK II, DXE drivers, Raspberry Pi Pico W
- Systems and Wayland: C, wlroots, Unix IPC
- Infrastructure: Linux administration, Docker, a homelab

## Projects

- [Leme](https://github.com/ernestoCruz05/leme): a tiling Wayland compositor in C17, built on wlroots.
- [PicoBootGate](https://github.com/ernestoCruz05/bootgate): pre-boot remote authorisation. The machine only boots with a network-issued ticket, and a USB-attached Pico W does the networking so the UEFI code stays small. It is the reference implementation for an academic paper.
- [PicoWifiDxe](https://github.com/ernestoCruz05/picodxe-showcase): a UEFI DXE driver that uses a Raspberry Pi Pico W as a WiFi adapter for firmware with no WiFi stack.
